# TaskLens v0.2.0

TaskLens v0.2.0 expands workspace navigation, release planning, and native
desktop support while making the main toolbar work better in constrained
windows.

## Highlights

- Navigate projects and views from the keyboard. Number keys select projects;
  `T`, `K`, `G`, `F`, and `U` open project views; `O` opens Overview; `A`
  toggles recent active work; `D` toggles completed tasks; and `/` focuses
  search. A centered animated confirmation makes every switch visible.
- Filter several priorities at once and open the in-app guide for an overview
  of TaskLens controls and shortcuts.
- Open an active-only Overview from the keyboard or the `ACTIVE · 1H` badge.
  It uses the same recent in-progress task definition as the badge.
- Group tasks by optional Product Features and review or remove selective
  unreleased change candidates before preparing a release.
- Use the native macOS menubar icon to show and focus TaskLens, and see the
  recent active-task count on the Dock icon.

## Navigation and layout

- Timeline is now the first project tab and the default view when a project is
  opened.
- Project, view, and touched-time controls switch to compact dropdowns when
  horizontal space is constrained.
- The top bar is shorter and denser, and no longer gives scarce navigation
  space to the active project's filesystem path.
- Responsive dropdown selections now remain synchronized with the current
  project, view, and touched-time filter.

## Reliability

- Projects added from Overview are restored after restarting a directory-based
  TaskLens session while duplicate ids and paths are ignored safely.
- Partially entered project details, keyboard focus, and cursor position survive
  live Overview updates and failed additions.
- The native desktop sidecar now starts from the real CLI entrypoint, waits for
  the local server to become ready, and bundles the frontend at the expected
  runtime path.

## Task workflow

- TaskLens now ships and uses one canonical repository-local task workflow,
  including skills for planning, selective release candidates, and safe task
  system upgrades.
- Wishlist is available as a separate planning status so visible ideas do not
  count as active work.
