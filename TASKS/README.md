# TaskLens tasks

This is TaskLens's repository-owned backlog. It follows the single canonical
task contract in
[`../templates/task-system/TASKS/README.md`](../templates/task-system/TASKS/README.md).

Only `NNNN-*.md` files at this directory's root are tasks. Numbered task files
stay in this repository and are never copied into the reusable template.
